아무것도 올라가지 않은 **흰 도우**가 주인공인 턴제 로그라이크입니다.

보통 로그라이크에서 적은 없애는 대상이지만, 이 게임에서 적은 **재료**입니다.
방울토마토를 쓰러뜨리면 방울토마토를 몸에 올릴 수 있습니다. 능력이 오르고 새콤한 기술이
열리지만, 도우가 무거워져 손놀림이 깎이고 여섯 칸뿐인 자리가 하나 줄어듭니다.

> **이 재료를 올릴 것인가, 지나칠 것인가.**

매콤과 새콤, 진한과 향긋은 같이 올리면 맛이 부딪칩니다. 칸을 비워 두면 약하고,
아무거나 채우면 맛이 무너집니다. **채우되 궁합을 봐야 합니다.**

8라운드에 도우가 구워지고, 10라운드 보스를 잡으면 소스가 발려 피자가 완성됩니다.
완성한 피자는 **도감 25칸**에 남습니다 — 실패해도 남는 유일한 것입니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드 (타입 검사 포함)
npm run sim      # 밸런스 시뮬레이션 1,200판
```
